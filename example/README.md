# Example / playground

Minimal Expo-ready screen that demos:

- `ThemeProvider` + `ThemeToggle`
- `ThemedView` / `ThemedText` / `ThemedStatusBar`
- `AnimatedThemeView`
- `ContrastPreview`
- `createAppTheme` / `themePresets`

## Try it

```bash
# from a new Expo app
npx create-expo-app playground
cd playground
npm install react-native-color-library
# copy App.tsx from this folder over the Expo App entry
```

Or link the local package:

```bash
npm install ../react-native-color-library
```
